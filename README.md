# Wolven Forge

Mod manager for *The Witcher 3: Wild Hunt*: bug reports, ideas and contact.

This repository is Wolven Forge's point of contact. The source code of the software isn't public: this is where bug reports, suggestions and requests to join the project live.

## Report a bug

1. Open the **Issues** tab, click **New issue** and choose **Report a bug**.
2. Give your Wolven Forge version (**Settings › About**), the game version, the mods involved and what you were doing.
3. If you can, attach the diagnostic file: **Export diagnostics…** in the **Diagnostics** workspace. It is redacted by default (personal paths and user name replaced) and never contains your saves, your mods' content or your launcher account. Nothing is sent automatically: you decide whether to share it.

Please never attach your saves or any credentials.

## Suggest an idea

Missing a feature? Open a **Suggest an idea** issue and describe the situation where it would help you.

## Join the project

Want to fix a bug or contribute code? Open a **Join the project** request describing what you'd like to do: I'm happy to open access to the code, case by case. By sending a contribution, you agree that it may be included in Wolven Forge.
